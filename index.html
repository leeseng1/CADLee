Source Control and Git

Understanding Version Control and the Basics of Git

What is Version Control?

Version control is a system that helps developers track and manage changes to files over time. It allows you to see what changes were made, who made them, and when they were made. If something breaks, you can revert back to a previous working version.

Version control is especially important when working in teams, because it allows multiple people to work on the same project without overwriting each other's changes.

Why Version Control is Important

  • History Tracking: Keep a complete history of changes.
  • Collaboration: Multiple developers can work on the same project safely.
  • Backup: Your code is stored in multiple places.
  • Experimentation: Try new ideas without affecting the main project.
  • Accountability: See who made specific changes.

What is Git?

Git is a distributed version control system created by Linus Torvalds in 2005. It is one of the most widely used version control systems in the world.

Git allows developers to track changes in their code, collaborate with others, and manage different versions of a project efficiently.

Because Git is distributed, every developer has a complete copy of the project’s history on their own machine.

Basic Git Concepts

Repository

A repository (or "repo") is a project folder that Git tracks. It contains your files and the entire history of changes. You create one using the command: git init

Commit

A commit is a snapshot of your project at a specific point in time. Each commit includes a message describing what changed.

Example commands: git add . followed by git commit -m "Your message"

Branch

A branch allows you to work on a separate line of development. This is useful for adding features or fixing bugs without affecting the main version of your project.

The default branch is usually called main. You can create a new branch using: git branch feature-name

Conclusion

Git and version control are essential tools for modern software development. They help you manage changes, collaborate with others, and maintain a reliable project history. Understanding repositories, commits, and branches is the first step toward mastering Git.
